LOCAL DASHBOARD 3.0.1

Before installing or switching copies, use File > Exit in any running Dashboard,
including a copy hidden in the system tray. Only one copy runs per Windows user.

INSTALL OR USE PORTABLE
Setup installs for your Windows account, normally under:
%LOCALAPPDATA%\Programs\Local Dashboard
Open Local Dashboard from the Start menu. A desktop shortcut is optional.

For portable use, extract the ZIP's App folder to a writable location and run
LocalDashboard.exe. Keep all supplied files and the Examples folder together.
Do not run the app from inside the ZIP.

Requirements: Windows 10 22H2 or Windows 11 on x64. The self-contained package
includes the .NET 10 runtime; no separate runtime installation is required.
The installer is unsigned. Compare downloaded files with the GitHub release's
SHA256SUMS.txt when verifying a download.

FIRST SETUP AND RESTORE
A fresh 3.0.1 release starts with empty Projects, Documents, Websites and All links
categories. No personal lists, icons or paths are included. Task list 1 and
Checklists are visible initially; Checklists starts empty. Generic examples in
the Examples folder can be selected manually if you want to try them.

To bring your existing setup, first use File > Back up configuration in the old
copy. In the new copy, choose Restore from a backup on the welcome screen, or
File > Restore configuration. Backups include readable custom icons and available
task-list/checklist copies. Restore reconnects included icons. Older backups
containing only icon paths need the original images or replacement icons.
Review each task-source choice before confirming and retain your original backup.

The walkthrough also lets you add your own first link and choose task files.
These steps are optional. Help > Run setup again reopens the walkthrough.
Start Here.txt provides instructions for assisted setup and maintenance.

EVERYDAY USE
Use Edit beneath the Dashboard sidebar to manage categories, links and icons.
For a website, a bare domain such as example.com is accepted and https:// is added.
Removing a link does not delete its destination. Settings > Appearance controls
All links visibility, theme and accent. Rapid color changes can leave the Windows
taskbar icon one color behind; pause between selections to let it refresh.

In Tasks, use Edit beneath the sidebar, or beside the tabs in Compact view, to
manage lists and items. Choose or create TXT/Markdown sources in Settings > Tasks.
Save connects new selections. Task views reread sources on entry; Refresh beside
Search rereads the selected list. Checklists checkoffs save automatically.

DATA, UPDATES AND UNINSTALL
catalog.json and .local live beside the executable. Linked task files stay in
their selected locations. An upgrade preserves an existing profile: reinstalling
does not reset it to blank. Back up before moving or manually changing files.
Uninstall offers Keep settings or Remove settings. Keep is the default. Task
files and checklist data are preserved even when settings are removed.
Help > Check for updates checks the latest stable GitHub release; it does not
install updates. A newer local version is identified without suggesting a downgrade.

HELP AND SUPPORT
F1 or Help > Help and user guide opens the built-in guide.
Help > Report an issue shows a notice, then Open GitHub opens the public issue
page in your browser. Cancel stays in the app. A GitHub account is required to
submit an issue. Nothing is submitted automatically. Include your app version,
Windows version and reproduction steps; omit private paths, task contents,
credentials and configuration backups.
https://github.com/DGX-Development/Local-Dashboard/issues/new
