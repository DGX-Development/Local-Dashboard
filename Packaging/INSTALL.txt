LOCAL DASHBOARD 2.2.3

Close any existing Local Dashboard using File > Exit before installing.

Setup installs for your Windows account, normally under:
%LOCALAPPDATA%\Programs\Local Dashboard

Open Local Dashboard from the Start menu. A desktop shortcut is optional.
A new profile starts with Projects, Documents, Websites and All links.
The first three contain one clearly labeled example each. Use Edit to change
names and destinations or reorder categories and links. Agent tasks and
Personal tasks start unselected. Checklists starts empty inside Dashboard.
No personal lists or paths are included. The setup walkthrough opens for a new profile. Help > Run setup again opens it later.

This download contains a starter catalog, not your personal files. To carry over
an existing Dashboard configuration, first use File > Back up configuration in
your existing copy. In the installed copy, use File > Restore configuration.
Review which restored copies Dashboard will use before confirming. Keep your original backup.

The catalog and .local settings/checklist folder live beside the executable.
Upgrades preserve existing catalog.json and .local data. Uninstall removes the
program but retains this data. Linked task documents stay in their own locations.
Back up configuration before manually editing or moving the application folder.

Agent tasks displays your selected agent-maintained text file. Personal tasks
can edit its selected text file. Checklists is the separate quick checklist.
Choose task file locations in Settings > Tasks. Save loads new selections.
Task views reread their files when opened. Use Refresh beside Checklists to reread all three lists. Cloud sign-in is coming soon;
local files in an already-synced folder can be selected now.

Local Dashboard 2.2.0 and newer share one running instance per Windows user.
Older builds do not contain the same guard. Retire old launchers after confirming
the installed copy works and your desired data has been restored.

Open a sample project folder, brief, or website. Use Edit below the sidebar to
manage categories, links, and icons. Add a link, choose what it opens, enter its
location, and Save. Removing a link keeps the original file or folder. Setup
includes an optional AI setup guide with a copyable planning prompt.

Help > Report an issue creates a report you can copy into a support message.
https://dgx.digitalguy.me/contact.html

Requirements: Windows 10 22H2 or Windows 11 on x64, with .NET Framework 4.8+.
The installer is unsigned. GitHub release SHA-256 checksums identify its files.
